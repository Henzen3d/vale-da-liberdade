# 🎶 Trilha de Fundo do Encerramento

Coloque nesta pasta o áudio/música instrumental que tocará no encerramento (outro).

- **Nome sugerido:** `outro_tema.wav` ou `outro_tema.mp3`
- **Formato ideal:** WAV 48.000 Hz, Stereo (ou MP3 320 kbps)
- **Duração recomendada:** 20 a 25 segundos (cobre os até 20s do vídeo com folga para fade out)
- **Comportamento no vídeo:** Toca como música de fundo (-18 dB) enquanto o apresentador fala o CTA de encerramento; assim que a fala termina, o sistema sobe o volume automaticamente (0 dB) por 2 a 3 segundos e finaliza com fade out até o segundo 20.
