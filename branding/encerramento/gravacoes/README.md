# 📹 Gravações dos Apresentadores para o Encerramento

Coloque nesta pasta os vídeos gravados em **tela cheia normal (1920x1080)** contendo as falas dos roteiros de encerramento (10s a 20s).

- **Formato:** MP4 (H.264 + AAC), 30fps ou 60fps.
- **Nomes sugeridos:** `outro_take_01.mp4`, `outro_take_02.mp4`, etc.
- **Como funciona:** O sistema redimensiona automaticamente o vídeo para a moldura de 1/4 de tela e insere sobre o fundo com os espaços livres para os cards do YouTube.
